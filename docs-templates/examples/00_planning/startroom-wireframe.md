# StartRoom 와이어프레임 v1.1

> 총 13개 화면 + 잠금화면 위젯 + 상태별 변화 정의

---

## 화면 목록

```
1.  온보딩 (4단계)
2.  홈 (상태 4가지)
3.  방 코드 참가 화면
4.  매칭 대기 화면 (즉시 시작 한정)
5.  시작방 생성 (목적 선택 → 시간 선택 → 예약 완료, 단계형 1/3~3/3)
6.  매칭 완료 팝업
7.  시작방 대기 (상태 4가지)
8.  스크럼 (상태 3가지 + Guide 스크럼)
9.  세션 (상태 4가지 + 바텀시트)
10. 잠금화면 위젯
11. 완료 + 회고 (한 스크롤)
12. Stats (주간 이동 + 공유 카드 미리보기)
13. 알림 목록
14. 회복 화면 (케이스 2가지)
15. 설정
```

---

## 공통 원칙

```
한 화면에 주요 CTA 1개
보조 CTA 1개 이하 (작게)
텍스트는 짧고 행동 중심
기준 틀 유지, 상태에 따라 내용만 변화
집중을 방해하지 않는 구조
```

🔔

[알림 허용하기]

```

```

## 2. 홈

헤더 고정. 상태에 따라 본문만 변화.

### 헤더

```
[📊]                    [🔔] [⚙️]
```

- 📊 → Stats 화면으로
- 🔔 → 알림 목록
- ⚙️ → 설정 화면

---

### 상태 1. 예약 없음

```
────────────────────────
[📊]                    [🔔] [⚙️]

지금 시작할까요?
10분이면 충분해요.

[시작방 만들기]
[방 코드로 참가하기]           ← 작게

────────────
12명이 지금 시작 중이에요.    ← 사회적 신호, 작게
────────────────────────
```

---

### 상태 2. 예약 있음 (시간 여유)

```
────────────────────────
[📊]                    [🔔] [⚙️]

내일의 시작은 잡아뒀어요.

┌──────────────────────┐
│ 개발 시작방      [...] │
│ 내일 오전 9:00        │
│                       │
│ [파트너 아바타]        │
│ 매칭 완료             │
│ 또는                  │
│ [공석] 파트너 찾는 중  │
└──────────────────────┘

────────────────────────
```

[...] 메뉴:
```
→ 지금 바로 시작하기
→ 시간 변경하기
→ 예약 취소
```

시간 변경 규칙:
```
매칭 전 + 시간 여유 → 자유 변경
매칭 후 + 1시간 이상 → 변경 가능, 파트너 알림 + 재매칭
매칭 후 + 1시간 이내 → 시간 변경 불가
                        지금 바로 시작만 가능
                        → 파트너 알림
                        → 즉시 재매칭 시작
                        → 10분 전까지 재매칭 시도
취소 → 언제든 가능, 파트너 알림 + 즉시 재매칭
```

## 3. 방 코드 참가 화면

홈에서 [방 코드로 참가하기] 눌러 진입.

```
────────────────────────
← 닫기

방 코드를 입력해주세요.

[______]                       ← 6자리 입력

[참가하기]

────────────────────────
```

예외 처리:
```
방이 진행 중 → 합류 화면으로 연결
방이 종료됨 → "이미 끝난 방이에요" 안내
잘못된 코드 → "코드를 다시 확인해주세요"
```

## 7. 스크럼

기준 틀 유지. 🔴 LIVE 표시로 시작대기방과 구분.
각자 자신의 할 일만 보임. 상대 할 일은 비공개.
말하는 사람 아바타에 🔊 아이콘.
먼저 입장한 사람이 먼저 말함.
할 일 목록은 시작방 대기에서 입력한 것을 그대로 표시. 스크럼 화면에서는 읽기 전용.

### 기준 틀

```
────────────────────────
[방 이름]
🔴 LIVE                        ← 고정

[아바타 섹션]                  ← 상태에 따라 변화

────────────
내 오늘 할 일                  ← 항상 보임, 참고용
• 할 일 1
• 할 일 2
• 할 일 3
────────────

[메시지]                       ← 상태에 따라 변화
[CTA 버튼]                     ← 상태에 따라 변화
────────────────────────
```

### Guide 스크럼 (실제 파트너 없을 때)

Guide는 목적별 미리 녹음된 음성 클립으로 먼저 말함.
사용자는 음성으로 할 일 말하고 준비완료 버튼.

```
────────────────────────

## 유저 플로우 요약

### Flow 1. 즉시 시작

```
홈
→ 시작방 생성 (1/3 → 2/3 지금 바로 → 3/3)
→ 매칭 대기 (30초)
→ 매칭 완료 팝업
→ 시작방 대기
→ 스크럼
→ 세션
→ 완료 + 회고
→ 홈
```

### Flow 2. 예약 시작

```
홈
→ 시작방 생성 (1/3 → 2/3 예약 → 3/3)
→ 홈 (예약 카드)
→ 알림 수신 (10분 전)
→ 시작방 대기
→ 스크럼
→ 세션
→ 완료 + 회고
→ 홈
```

### Flow 3. 매칭 완료 재접속

```
매칭 완료 알림
→ 앱 열기
→ 매칭 완료 팝업
→ [좋아요] → 홈 (카드 상태 업데이트)
```

### Flow 4. 지인 초대 진입

```
초대 링크 클릭
→ 앱 설치
→ 온보딩 (간소화)
→ 같은 방 자동 배정
→ 시작방 대기
→ 스크럼
→ 세션
→ 완료 + 회고
→ 홈
```

### Flow 5. 예약 놓침 회복

```
홈 카드 "종료됨"
→ [새로 예약하기]
→ 시작방 생성
→ 홈
```

### Flow 6. 방 코드 참가

```
홈
→ [방 코드로 참가하기]
→ 방 코드 입력
→ 시작방 대기 (진행 중이면 합류 화면)
→ 스크럼
→ 세션
→ 완료 + 회고
→ 홈
```

### 구멍 1. 매칭 대기 이탈
```
보완
→ 대기 화면에 진행 상황 표시
   "주변에 3명이 시작 준비 중이에요"
→ 15초 후 "곧 찾을 수 있을 것 같아요"
→ 30초 후 Guide 즉시 배정
```

### 구멍 2. 지인 초대 중 시작 시간 초과
```
보완
→ 설치 완료 후 자동 상태 확인
→ 진행 중이면 합류 화면
→ 종료됐으면 회복 화면
```

### 구멍 3. 마이크 권한 미허용 후 스크럼 진입
```
보완
→ 스크럼 진입 직전 마이크 권한 재요청
→ 거절하면 텍스트 스크럼으로 자동 전환
→ 파트너에게 "상대방이 텍스트로 진행해요" 표시
```

## 출시 우선순위

```

완료 + 회고

### v2 이후
```

→ 없어도 세션 작동에 문제 없음
→ 앱 복귀 시 세션 복귀는 v1 필요

→ 초기엔 이번 주 기록만으로 충분

→ 완료 + 회고 화면 하단에 선택적으로 추가

## Guide 경험 설계

> 앱 초기에는 대부분의 세션이 Guide와 진행된다.
> Guide 경험이 곧 앱의 첫인상이다.
> Guide와 할 때도 와우모먼트가 동일하거나 더 높아야 한다.

### Guide 경험 원칙
```
1. Guide는 봇처럼 느껴지면 안 된다
2. 음성이 있어야 실재감이 생긴다
3. 세션 중 조용한 신호가 연결감을 만든다
4. 완료 때 따뜻한 멘트가 와우모먼트를 완성한다
5. 항상 있다는 것이 Guide의 강점이다
   (실제 파트너는 노쇼 가능, Guide는 항상 대기)
```

---

### Guide 스크럼

실제 파트너와 동일한 틀. 단, Guide는 목적별 미리 녹음된 음성 클립으로 대체.

```
Guide 음성 클립 (목적별)
→ 개발: "오늘 개발 작업 함께 시작해요. 파이팅이에요!"
→ 공부: "오늘 공부 함께 시작해요. 잘 하실 수 있어요!"
→ 업무: "오늘 업무 함께 시작해요. 좋은 하루 되세요!"
→ 글쓰기: "오늘 글쓰기 함께 시작해요. 첫 문장이 시작이에요!"
→ 기타: "오늘도 함께 시작해요. 파이팅이에요!"
```

### Guide 세션

세션 중 상태 메시지와 조용한 응원 신호로 존재감 유지.

```

→ "Guide도 함께 집중 중이에요."

10분 도달 시
→ "10분 완료. Guide도 함께했어요."

10분 이후
→ "계속 함께 집중 중이에요."

15분 경과마다 조용한 응원 신호
→ 화면 하단에 아주 작게
   "Guide: 잘 하고 있어요 👊"
