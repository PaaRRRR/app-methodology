# StartRoom 개발 기획서 v2.0

> 혼자 일하는 사람의 매일 아침 출근 동료

---

## 0. 제품 정의

### 0-1. 한 줄 정의

> **StartRoom은 혼자 일하는 사람이 매일 계획대로 시작하고, 그게 쌓여서 자기 자신을 믿게 되는 앱이다.**

### 0-2. 핵심 포지셔닝

생산성은 수단이다. StartRoom의 본질은 **자기 효능감의 회복과 축적**이다.

| 서비스 | 포지션 |
|--------|--------|
| Focusmate | 화상 바디더블링, 영어권 중심, 카메라 필수 |
| Forest | 혼자 집중, 소셜 요소 없음 |
| Todoist / 노션 | 할 일 관리, 시작 트리거 없음 |
| Beeminder | 강제성 기반, 스트레스 높음 |
| **StartRoom** | **매일 계획대로 살아내는 앱 (비어있는 포지션)** |

### 0-3. 핵심 피칭 문장

> 매일 혼자 일을 시작하지 못하는 사람들을 위해, 파트너와 함께 계획대로 하루를 시작하고 그 기록이 쌓여 자기 자신을 믿게 만드는 앱입니다.

짧게는:

> **혼자 일하는 사람의 매일 아침 출근 동료**

## 1. 핵심 문제

### 1-1. 문제 맥락

프리랜서와 1인 개발자는 구조적으로 시작을 강제하는 외부 장치가 없다. 출근 시간도 없고, 옆에 동료도 없고, 상사도 없다. 자유가 곧 약점이 되는 환경이다.

### 1-2. 핵심 문제 3가지

**시작 마찰**
할 일을 알고 있는데 첫 행동으로 넘어가는 게 안 된다. 유튜브나 SNS 같은 즉각적인 보상이 경쟁하기 때문이다.

**구조 부재**
오피스 환경은 암묵적으로 "지금은 일하는 시간"이라는 신호를 계속 준다. 재택/1인 환경은 이 신호가 없어서 뇌가 일 모드로 전환이 안 된다.

**고립감**
혼자 일하면 누가 보지 않아도 되니까 미뤄도 아무도 모르고, 그게 오히려 더 쉽게 미루게 만든다.

### 1-3. 붕괴 패턴

```
전날 밤 → "내일 9시에 시작해야지" 결심
아침 8시 → 일어남
8시 10분 → 폰 봄
8시 40분 → 유튜브 봄
9시 → 알림 옴, 무시함
9시 20분 → 죄책감 생김
9시 30분 → "오늘도 망했다" 모드 진입
→ 하루 전체가 망가짐
```

## 2. 결과값과 와우모먼트

### 2-1. 사용자의 진짜 결과값

**결과값 (본질)**
- 내가 원하는 걸 실제로 만들어내고 싶다
- 미루다가 하루가 끝나는 게 너무 괴롭다
- 나 자신에 대한 신뢰가 무너지는 게 싫다

**수단값**
- 생산적으로, 계획적으로 하루를 보내고 싶다

### 2-2. 와우모먼트 4단계

와우모먼트는 한 번이 아니라 4개의 연속된 감각으로 이루어진다.

```
1. 시작 와우 → "계획한 시간에 실제로 시작했다"
2. 진행 와우 → "지금 계획대로 흘러가고 있다"
3. 완료 와우 → "오늘 해야 할 걸 실제로 마쳤다"
4. 축적 와우 → "나는 꾸준히 하는 사람이 되어가고 있다"
```

### 2-3. 핵심 바이럴 모먼트

가장 강력한 바이럴 순간은 **"이번 주 기록"을 봤을 때**다.

> "나 원래 이런 사람 아니었는데" — 이 감각이 공유를 만든다.

**바이럴 루프**

```
이번 주 기록 카드 공유
→ 지인이 앱 설치
→ 첫 시작 성공
→ 지인 초대
→ 같이 시작
→ 둘 다 기록 쌓임
→ 둘 다 카드 공유
```

**자연 바이럴 + 의도적 바이럴**

- 자연 바이럴 → 기록 카드 공유 (D+0 첫 시작 카드, D+7 이번 주 카드)
- 의도적 바이럴 → 지인 초대 링크 (같이 시작하자는 제안)

## 3. 핵심 가설

**가설 1. 파트너 효과**
> 파트너와 함께 시작하면 실제로 시작률이 높아지는가?

**가설 2. 축적 효과**
> 기록이 쌓이면 다시 돌아오는가?

## 4. 전체 앱 흐름

> StartRoom은 사용자의 하루에 조용히 함께 있는 앱이다.
> 시작할 때 강하게 개입하고, 진행 중엔 조용히 있고, 끝날 때 다시 나타나 기록하고, 쌓이면 보여준다.

### 4-0. 시작방 생성

모든 시작은 동일한 포맷이다. 즉시 시작과 예약 시작을 별도 버튼으로 나누지 않는다. 시간 선택에서 "지금 바로"를 선택하면 즉시 시작이 된다.

```
[시작방 만들기] 버튼 하나
→ 목적 선택
→ 시간 선택
   [지금 바로] ← 강조
   [10분 후]
   [30분 후]
   [오늘 오후 2시]
   [직접 선택]
→ 파트너 매칭
→ 시작
```

1. 익명 사용자 생성 (가입 없이)
2. 시작방 예약 (시간 + 목적 선택)
3. 방 생성 후 파트너 매칭 → 지인 초대(링크 하나로) or 유사 유저 or Guide

### 4-1. 시작 트리거 (앱이 사용자를 부른다)

- 1시간 전 알림 → "오늘 9시 개발 시작방, 파트너가 배정됐어요"
- 10분 전 알림 → "방이 열렸어요. 파트너가 기다리고 있어요"

### 4-2. 입장

- 어제 기록 한 줄 보여줌
- 오늘 할 것 1~3개 입력
- 첫 번째 할 일 확정
- 준비 완료 버튼

### 4-3. 스크럼 (음성, MVP)

음성이 켜지면 먼저 입장한 사람이 오늘 할 일 한 마디. 파트너가 응답. 각자 준비완료 버튼. 둘 다 누르면 카운트다운 시작. 음성 off 후 세션 시작.

```
입장 완료
→ 음성 자동 켜짐
→ 먼저 입장한 사람에게 신호: "오늘 할 일 한 마디 해볼게요"
→ 말하고 나면 파트너 차례
→ 각자 [준비완료] 버튼
→ 파트너 준비완료 시 상대에게 신호: "파트너가 준비됐어요 👊"
→ 둘 다 누르면 카운트다운
→ 음성 off
→ 세션 시작
```

> MVP는 음성으로만. 이후 영상 옵션 추가 예정.

### 4-4. 진행 (앱이 전면 유지)

세션 화면은 기본적으로 전면에 유지된다. 사용자가 직접 홈버튼을 누르면 백그라운드로 가지만, 잠금화면에 타이머와 파트너 신호가 표시된다. 앱 종료 후 돌아오면 세션 화면으로 즉시 복귀한다. 시작 종료를 누르기 전까지 세션은 계속 살아있다.

```
세션 화면 전면 유지
→ 사용자가 홈버튼 누르면 백그라운드
→ 잠금화면 표시: "개발 시작방 진행 중 / 파트너 집중 중 · 23:14"
→ 앱 종료 후 복귀 시 세션 화면 즉시 복귀
→ 파트너 집중 중 신호 표시
→ 파트너 투두리스트 선택적으로 보기 (ON/OFF)
```

### 4-5. 완료 - 회고 (앱이 다시 전면으로)

완료는 강제가 아니라 자연스러운 마무리다. 각자 독립적으로 종료하며, 파트너 종료 시 부드러운 신호만 전달한다.

**회고 흐름**

1. 오늘 할 일 목록 체크 (완료 / 미완료)
2. 한 줄 소감 입력
3. 파트너에게 칭찬 스티커 전송
4. [오늘 마무리하기] 버튼 → 업무 off 신호

**파트너 종료 신호**

```
"파트너가 세션을 마쳤어요."
"마무리할 준비가 됐나요?"
→ [조금 더 하기] / [나도 마치기]
```

### 4-6. 축적 (앱이 거울이 됨)

- 이번 주 기록 (시작 횟수, 시간대, 달성률)
- 첫 시작 공유 카드 (D+0 즉시 공유 가능)
- 이번 주 기록 공유 카드 (D+7 강력 바이럴)
- Milestone 알림: "3일 연속 시작했어요"

## 5. 파트너 매칭 시스템

### 5-1. 매칭 우선순위

```
1순위 → 내가 초대한 지인
2순위 → 시간 + 목적이 유사한 낯선 사용자
3순위 → StartRoom Guide
```

### 5-2. 즉시 시작 vs 예약 시작 매칭 타이밍

**즉시 시작**
```
지인 초대 없음 (시간이 없음)
→ 유사 유저 매칭 시도 (30초 이내)
→ 없으면 Guide 즉시 배정
```

**예약 시작**
```
예약 즉시 → 지인 초대 링크 생성 가능
시작 1시간 전 → 유사 유저 매칭 시도
없으면 → Guide 배정
시작 10분 전 → 최종 파트너 확정 알림
```

### 5-3. 지인 초대 흐름

**초대하는 사람**
```
시작방 예약 완료
→ "같이 시작할 지인을 초대할 수 있어요"
→ [지인 초대하기] / [그냥 매칭받기]
→ 카카오톡 / 문자 / 링크 복사로 전송
```

**초대받은 사람**
```
링크 클릭
→ "[친구 이름]님이 내일 9시 개발 시작방에 초대했어요"
→ [함께 시작하기]
→ 앱 설치 or 바로 진입 → 같은 방 배정
```

**지인 무응답 처리**
> "지인이 아직 응답 안 했어요. 시작 시간까지 응답 없으면 자동으로 파트너를 찾아드릴게요."

### 5-4. Guide 정책

**작동 방식 (MVP - 완전 자동화 봇)**
```
스크럼 → 미리 정해진 멘트
오늘 할 일 목적에 맞는 짧은 격려
타이머 신호 자동
칭찬 스티커 자동 발송
회고 때 짧은 마무리 멘트
```

**표현 원칙**
- Guide는 사람인 척하지 않는다
- 파트너 노쇼 감지 즉시 Guide로 자동 전환

올바른 표현:
```
같이 시작할 상대: StartRoom Guide
```

잘못된 표현:
```
익명의 시작러가 매칭되었어요
```

### 5-5. 파트너 신뢰 신호 (MVP)

점수 시스템은 MVP에서 제외. 가벼운 신뢰 신호만 표시.

```
이 파트너는 시작방 12회 완료 · 최근 7일 활동 중
```

> 점수 시스템은 유저가 충분히 쌓인 후 A/B 테스트로 검증.

## 6. MVP 범위

### 6-1. 단계별 가설 검증

**Step 1. 혼자 시작 검증**
```
목적 선택
시간 선택 (지금 바로 / 예약)
시작방 생성
Guide 즉시 배정
오늘 할 일 1~3개 입력
10초 카운트다운
10분 세션
완료 회고
기록 저장
```
검증 포인트: 할 일을 입력하면 실제로 시작률이 높아지는가?

---

**Step 2. 파트너 시작 검증**
```
파트너 매칭 (유사 유저 or Guide)
음성 스크럼
진행 중 파트너 신호
칭찬 스티커
```
검증 포인트: Guide라도 파트너가 있으면 완료율이 높아지는가?

---

**Step 3. 지인 초대 검증**
```
지인 초대 링크 생성
같은 방 배정
첫 시작 공유 카드
```
검증 포인트: 지인 초대가 실제 사용자 획득으로 이어지는가?

---

**Step 4. 축적 검증**
```
이번 주 기록 화면
이번 주 기록 공유 카드
Milestone 알림
재방문율 측정
```
검증 포인트: 기록이 쌓이면 다시 돌아오는가?

### 6-2. Must Have

**시작방 생성**
- 익명 사용자 생성 (가입 없이)
- 목적 선택
- 시간 선택 (지금 바로 / 예약, 동일한 포맷)
- 시작방 생성
- 파트너 매칭 (지인 > 유사 유저 > Guide)
- 지인 초대 링크
- 1시간 전 파트너 배정 알림, 10분 전 입장 알림

**입장 + 스크럼**
- 어제 기록 한 줄
- 오늘 할 일 1~3개 입력
- 음성 스크럼 (순서 지정, 준비완료 버튼)
- 10초 카운트다운

**진행**
- 세션 타이머 (전면 유지)
- 백그라운드 시 잠금화면 표시
- 앱 종료 후 복귀 시 세션 화면 즉시 복귀
- 파트너 집중 중 신호

**완료**
- 각자 독립 종료
- 파트너 종료 시 부드러운 신호
- 칭찬 스티커 전송
- 오늘 할 일 체크 + 한 줄 소감
- [오늘 마무리하기] 버튼
- 다음 시작방 예약 제안

**축적**
- 이번 주 기록
- 첫 시작 공유 카드
- 이번 주 기록 공유 카드

### 6-3. Should Have

- 파트너 투두리스트 실시간 공유 (ON/OFF)
- 칭찬 스티커 종류 확장

- 음성 스크럼 → 영상 옵션 추가

### 6-4. Not Now

- 채팅 / 친구 추가 / 팔로우

## 11. 개발 구현 우선순위

### Step 1. 기본 앱 구조
```
익명 user_id 생성 (가입 없이)
홈 화면
라우팅
기본 디자인 시스템
```

### Step 2. 시작방 생성 플로우
```
목적 선택
시간 선택 (지금 바로 / 예약, 동일한 포맷)
시작방 생성
예약 완료 화면 (예약인 경우)
홈에 예약 상태 표시
```

### Step 3. 파트너 매칭
```
즉시 시작
→ 유사 유저 매칭 시도 (30초 이내)
→ 없으면 Guide 즉시 배정

예약 시작
→ 예약 즉시 지인 초대 링크 생성
→ 시작 1시간 전 유사 유저 매칭 시도
→ 없으면 Guide 배정
→ 시작 10분 전 최종 파트너 확정 알림
```

### Step 4. 시작방 대기 + 스크럼
```
시작방 대기 화면
파트너 / Guide 표시
음성 스크럼
→ 먼저 입장한 사람 순서 지정
→ 오늘 할 일 한 마디
→ 각자 준비완료 버튼
→ 둘 다 누르면 카운트다운
→ 음성 off
```

### Step 5. 세션
```
10초 카운트다운
세션 화면 (앱 전면 유지)
타이머 (백그라운드 가도 잠금화면 표시)
파트너 집중 중 신호
앱 종료 후 복귀 시 세션 화면 즉시 복귀
10분 도달 시 상태 변화
```

### Step 6. 완료 + 회고
```
각자 독립 종료
파트너 종료 시 부드러운 신호
칭찬 스티커 전송
오늘 할 일 체크
한 줄 소감
[오늘 마무리하기]
다음 시작방 예약 제안
```

### Step 7. 축적 + 공유
```
이번 주 기록 화면
첫 시작 공유 카드
이번 주 기록 공유 카드
Milestone 알림 (3일 연속 등)
```

### Step 8. 알림 + 트래킹
```
1시간 전 파트너 배정 알림
10분 전 입장 알림
예약 시간 놓침 감지 + 회복 화면
이벤트 트래킹 전체
```

### Guide 작동 방식 (MVP - 완전 자동화 봇)
```
스크럼 → 미리 정해진 멘트
오늘 할 일 목적에 맞는 짧은 격려
타이머 신호 자동
칭찬 스티커 자동 발송
회고 때 짧은 마무리 멘트
```

## 13. 핵심 개발 원칙

1. 사용자를 오래 붙잡지 말고, 실제 행동으로 보내라.
2. 실패를 비난하지 말고, 다시 시작할 길을 보여줘라.
3. 모든 시작은 파트너와 함께다. 혼자 시작하는 케이스는 없다.
4. Start Pact는 리텐션과 책임감을 만드는 장치다.
5. StartRoom Guide는 사람인 척하지 않는다.
6. 모든 기능은 시작률 또는 재시작률에 기여해야 한다.
7. MVP에서는 시작을 돕지 않는 소셜 기능을 넣지 않는다.
8. 앱은 사용자의 하루에 조용히 함께 있어야 한다.
