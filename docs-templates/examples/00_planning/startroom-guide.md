# StartRoom 프로젝트 요약

## 앱 개요

**StartRoom**은 혼자 시작하기 어려운 사람들을 위한 파트너 기반 집중 시작 앱이에요.
매일 익명의 파트너와 짧은 스크럼(30초)을 하고, 함께 세션을 시작하는 루틴을 만들어줘요.

---

## 핵심 가설

> "혼자는 시작이 어렵지만, 누군가와 함께라면 시작할 수 있다."

- 완벽한 집중이 목표가 아니라 **시작 자체**가 목표
- 파트너는 익명 — 부담 없이, 그냥 같이 시작하는 사람
- 10분만 버티면 흐름이 생긴다

---

## MVP 범위

### 포함
- 즉시 시작 플로우 (방 생성 → 매칭 → 대기 → 스크럼 → 세션 → 완료)
- 예약 시작 플로우
- 파트너 매칭 (익명)
- 스크럼 (음성, 30초)
- 세션 타이머
- 완료 + 회고 (스티커, 한 줄 소감)
- 기본 Stats (주간 기록)
- 알림 (시작 10분 전, 매칭 완료)
- 로그인 없음 (기기 저장)

### 제외 (v2 이후)
- 인증 기능 (셀로그 스타일 사진/영상)
- 공유하기 카드
- PRO 플랜 (즉시 매칭)
- QR 코드 참가
- 로그인/계정

### 폰트
- Pretendard (한/영 모두)
- Display 72px / Title 28px / Body 17px / Caption 13px

### 핵심 원칙

- 카피 톤 → v1 스타일 (활기차고 직접적)
- 타이포/여백 → 정제되고 넉넉하게

## 플로우 정리

### 즉시 시작
```
홈(빈) → 시작방 만들기 → 목적 선택 → 시간(지금 바로)
→ 완료화면(매칭중) → 매칭 대기 → 매칭 완료 팝업
→ 시작방 대기 → 스크럼 → 카운트다운 → 세션 → 완료
```

### 예약
```
홈(빈) → 시작방 만들기 → 목적 선택 → 시간(예약)
→ 완료화면(예약) → 홈(예약 있음)
→ [당일 D-10분] 홈(D-10분) → 입장 → 매칭 완료 팝업
→ 시작방 대기 → 스크럼 → 카운트다운 → 세션 → 완료
```
